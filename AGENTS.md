## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `kienhienh/BC93_capstone`. See `docs/agents/issue-tracker.md`.

### Issue delivery

When an issue is complete (all applicable acceptance criteria are checked and required quality gates pass), create one dedicated pull request for that issue. Link automatic closure with `Closes #<issue-number>`. Keep one issue per pull request unless the repository owner explicitly approves grouping.

### Triage labels

The repo uses the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo using root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
